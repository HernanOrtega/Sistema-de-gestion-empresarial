# Sistema de Gestión Empresarial

Aplicación de escritorio desarrollada como proyecto académico utilizando C++, Qt 6 y PostgreSQL.

## Tecnologías

- **Lenguaje:** C++17
- **Framework e interfaz gráfica:** Qt 6 / Qt Widgets
- **Acceso a datos:** Qt SQL mediante el controlador QODBC
- **Base de datos:** PostgreSQL
- **Reportes:** HTML

## Funcionalidades

El proyecto contiene módulos para la gestión de:

- Clientes, proveedores y empleados.
- Productos, marcas, categorías y stock.
- Ventas, compras y pedidos.
- Presupuestos y cotizaciones.
- Caja, arqueos, cobros y pagos.
- Cuentas por cobrar y cuentas por pagar.
- Usuarios y auditoría.
- Generación de reportes en HTML.
